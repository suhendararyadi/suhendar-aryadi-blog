# LKPD Digital TIK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement interactive LKPD Digital for Elemen 2 TIK (`/belajar/informatika/tik/lkpd.astro`), submission & grading APIs, database migrations on Neon Postgres, and upgrade the teacher admin portal (`/admin/lkpd.astro`) with dual LKPD BK/TIK tab filtering.

**Architecture:** Create `lkpd_tik_submissions` table via `scripts/migrate.js`, build student LKPD TIK Astro page and API submit endpoint, build teacher grading endpoint, and update admin LKPD dashboard to review and grade TIK submissions.

**Tech Stack:** Astro v4 (SSR), Neon Postgres, HTML5, Vanilla CSS, TypeScript.

## Global Constraints

- Pure Vanilla CSS without Tailwind.
- High visual aesthetics: clean typography without emoji clutter in headers/badges.
- Flexible `<textarea>` input fields for mobile ergonomics.
- Enforce authentication check and LKPD assignment deadline.
