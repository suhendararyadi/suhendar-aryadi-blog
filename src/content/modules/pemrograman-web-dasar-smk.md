# Modul Pemrograman Web Dasar - Kelas X RPL

Selamat datang di **Modul Pembelajaran Pemrograman Web Dasar** untuk siswa SMK Kelas X Jurusan Rekayasa Perangkat Lunak (RPL). Modul ini dirancang untuk memberikan pemahaman dasar hingga menengah mengenai konsep pengembangan web front-end.

---

## Informasi Modul

- **Mata Pelajaran:** Pemrograman Web dan Perangkat Bergerak
- **Tingkat / Kelas:** X (Sepuluh) RPL
- **Alokasi Waktu:** 12 Jam Pelajaran (3 Pertemuan)
- **Penyusun:** Suhendar Aryadi, S.Kom.

---

## Capaian Pembelajaran (CP)

Peserta didik mampu memahami struktur dokumen HTML5, menerapkan pengayakan visual menggunakan CSS3, serta membangun halaman web statis yang responsif dan sesuai dengan standar aksesibilitas web.

---

## Ringkasan Materi Pembelajaran

### Bab 1: Pengenalan HTML5
- Elemen dan Tag Dasar (`<html>`, `<head>`, `<body>`, `<h1>`-`<h6>`, `<p>`)
- Membuat List, Table, dan Form Interaktif
- Semantic HTML (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)

### Bab 2: Dasar CSS3 & Styling
- Selector, Property, dan Value dalam CSS
- Box Model (Margin, Border, Padding, Content)
- CSS Layouting dengan Flexbox dan CSS Grid

### Bab 3: Proyek Akhir - Landing Page Sederhana
- Menggabungkan HTML5 dan CSS3 untuk membuat halaman web profil siswa.
- Mengunggah proyek ke platform hosting gratis (GitHub Pages / Vercel).
